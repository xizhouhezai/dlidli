## 版本总览

| 版本 | 周期 | 主题 | 终端 | 目标 |
| --- | --- | --- | --- | --- |
| **MVP (V0.5)** | 第 1-3 月 | 跑通"投稿→审核→观看"闭环 | Web + 管理后台 | 内测可用 |

## MVP（V0.5）—— 核心闭环

**原则：能砍则砍，只保留"看视频"必需的能力。**

| 模块 | 范围 |
| --- | --- |
| 账号 | 邮箱/手机号注册登录、JWT 会话、基础资料 |
| 投稿 | 单文件上传（分片续传）、标题/封面/分区/标签、提交审核 |
| 转码 | FFmpeg 转 HLS，360P/720P 两档 |
| 播放 | Web 播放器（清晰度切换、倍速、进度记忆） |
| 弹幕 | 发送 + 按时间轴展示（滚动弹幕，基础样式） |
| 互动 | 点赞、评论（一级+二级） |
| 列表 | 首页按分区最新/最热列表（不做个性化推荐） |
| 后台 | 稿件人工审核（通过/驳回）、用户封禁 |

**明确不做**：投币/收藏、私信、动态、推荐算法、直播、会员。

## V1.0 —— 互动与社区

- 互动补全：投币、收藏（收藏夹）、一键三连、转发
- 弹幕进阶：顶部/底部/彩色弹幕、弹幕屏蔽（关键词/用户/密度）、弹幕举报
- 关注体系：关注/粉丝、动态流（投稿动态 + 文字动态）
- 消息中心：回复我的、@我、收到的赞、系统通知
- 搜索：视频/UP 主搜索（Elasticsearch）、搜索联想、历史记录
- 用户成长：经验等级 Lv0-Lv6、每日任务、硬币获取规则
- H5 端上线：观看、互动、个人中心
- 机审接入：图像/文本内容安全 API 预筛

## V2.0 —— 分发与创作者生态

- 推荐系统：首页个性化推荐（召回+粗排，协同过滤起步）、相关视频推荐
- 热榜体系：全站排行榜、分区排行榜、每周必看
- 创作者中心：数据分析（播放/互动/粉丝画像）、稿件管理增强（数据对比）、粉丝管理
- 创作激励：流量扶持计划、创作激励金（按有效播放结算）
- 合集与分P：多P投稿、视频合集、连播
- 小程序上线：观看 + 分享裂变
- 私信系统：一对一私信、消息盒子
- 运营平台：Banner 配置、活动页、热搜运营、A/B 实验开关

## V3.0 —— 商业化与直播

- 大会员：连续包月/年、高清 4K、专属标识
- 充电计划：观众直接打赏 UP 主，平台分成
- 广告系统：信息流广告位、品牌起飞（流量购买）
- 直播：开播工具、RTMP 推流、直播间弹幕/礼物、直播回放转稿件
- App：iOS/Android 原生或跨端方案，离线缓存、消息推送
- 开放平台：第三方投稿 API、数据开放

## 版本间依赖关系

```
MVP 闭环 ──→ V1 互动社区 ──→ V2 推荐分发 ──→ V3 商业化
   │              │                │              │
   账号/视频/审核   关注/消息/搜索     数据体系/算法    支付体系/直播
```
