# PRD：弹幕系统

> 优先级：`P0`（基础）/ `P1`（进阶） ｜ 版本：MVP 起 ｜ 状态：草案

## 1. 需求背景

弹幕是产品差异化核心，营造"一起看"的陪伴感。需兼顾表达自由与观看体验（防遮挡、防刷屏）。

## 2. 功能需求

### 2.1 弹幕发送（MVP）

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| DM-01 | 发送滚动弹幕 | 登录 + Lv1 以上可发；≤100 字；绑定视频时间点（精确到毫秒） | P0 |
| DM-02 | 弹幕样式 | 字号（小/标准）、颜色（白色默认；彩色需 Lv3） | P1 |
| DM-03 | 弹幕模式 | 滚动（默认）/ 顶部固定 / 底部固定 | P1 |
| DM-04 | 发送频控 | 同一用户同一视频 5s 内限 1 条；重复内容 30s 去重 | P0 |
| DM-05 | 高级弹幕 | 自定义位置/动画（消耗硬币） | P3（远期） |

### 2.2 弹幕展示（MVP）

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| DM-10 | 时间轴加载 | 按分段（6min/段）拉取弹幕，随播放进度渲染 | P0 |
| DM-11 | 弹幕开关 | 一键开/关，状态记忆 | P0 |
| DM-12 | 展示设置 | 不透明度、字号缩放、显示区域（1/4、半屏、全屏）、速度 | P1 |
| DM-13 | 密度控制 | 同屏弹幕上限（默认自适应），超出按权重丢弃（优先保留高赞/高等级用户弹幕） | P1 |
| DM-14 | 防挡字幕 | 智能防遮挡（人脸/字幕区域避让） | P3 |
| DM-15 | 实时弹幕 | 同时在看的用户弹幕通过 WebSocket 实时下发 | P1 |

### 2.3 弹幕治理

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| DM-20 | 关键词屏蔽 | 用户自定义屏蔽词（≤200 个） | P1 |
| DM-21 | 屏蔽用户 | 屏蔽指定用户弹幕（按哈希，不暴露 UID） | P1 |
| DM-22 | 弹幕举报 | 举报类型：违法违规/人身攻击/剧透/刷屏 | P1 |
| DM-23 | UP 主弹幕管理 | UP 主可删除自己视频下的弹幕、设置弹幕关键词黑名单 | P2 |
| DM-24 | 机审过滤 | 发送前经敏感词 + 内容安全接口过滤，命中则仅发送者可见（影子屏蔽）或拒绝 | P0 |

## 3. 关键交互

- 弹幕输入框固定于播放器下方；发送后本地立即上屏（乐观展示）。
- 悬停弹幕可暂停滚动，展开操作：点赞 / 复制 / 举报 / 屏蔽发送者。
- 弹幕列表面板（Web）：按时间排序查看全部弹幕。

## 4. 数据结构要点

```
弹幕 { id, video_id, user_id, content, time_ms(视频内时间),
       mode(滚动/顶/底), color, font_size, status, created_at }
```

- 存储：MySQL 持久化 + Redis 分段缓存（video_id + 分段号）。
- 实时通道：WebSocket 按视频房间广播。

## 5. 指标与边界

- 弹幕加载耗时 P90 < 200ms（缓存命中）。
- 单视频弹幕池上限（如 8000 条/6min 段），超出按权重淘汰展示。
- 视频被锁定时弹幕停止对外展示。
