# PRD：互动体系（点赞 / 投币 / 收藏 / 评论 / 三连）

> 优先级：`P0`（点赞/评论）/ `P1`（投币/收藏/三连） ｜ 状态：草案

## 1. 需求背景

互动是社区活跃度与内容分发权重的核心信号。"三连"是平台文化符号，投币消耗硬币建立"付出感"，比单纯点赞更能代表内容质量。

## 2. 功能需求

### 2.1 点赞（MVP）

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| ITR-01 | 视频点赞/取消 | 单账号单视频一次；计数实时展示（缓存计数 + 异步落库） | P0 |
| ITR-02 | 评论/弹幕点赞 | 影响评论排序（热度） | P0 评论 / P1 弹幕 |
| ITR-03 | 点踩 | 仅作为负反馈信号，不展示计数 | P2 |

## 3. 防刷与风控

- 点赞/投币/收藏接口按 UID+IP 限频；设备指纹识别刷量团伙。
- 互动计数异常检测（短时激增触发风控复核，剔除作弊量）。
- 硬币操作需强一致（事务），防止并发重复投币。

## 4. 指标

- 互动接口 P99 < 200ms；计数最终一致延迟 < 5s。
- 目标三连率（三连数/播放量）≥ 1.5%，评论率 ≥ 2%。
