# PRD：视频投稿与播放

> 优先级：`P0` ｜ 版本：MVP 起 ｜ 状态：草案

## 1. 需求背景

视频是平台核心资产。本模块覆盖：上传 → 转码 → 审核 → 发布 → 播放的完整生命周期。

## 2. 分区设计（一级分区）

动画 ｜ 游戏 ｜ 科技数码 ｜ 知识 ｜ 生活 ｜ 美食 ｜ 音乐 ｜ 舞蹈 ｜ 影视 ｜ 体育 ｜ 时尚 ｜ 娱乐

> 每个一级分区下设二级分区（V1 上线），由运营后台可配置。

## 3. 功能需求

### 3.1 投稿（Web 端，MVP）

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| VID-01 | 视频上传 | 分片上传（5MB/片）、断点续传、秒传（文件 hash）；单文件 ≤ 8GB；格式 mp4/mov/mkv/flv/avi | P0 |
| VID-02 | 稿件信息 | 标题（≤80 字）、简介（≤2000 字）、分区（必选）、标签（1-10 个）、类型（自制/转载，转载需注明出处） | P0 |
| VID-03 | 封面 | 自定义上传（16:10）或从视频抽帧候选中选择 | P0 |
| VID-04 | 定时发布 | 审核通过后按预约时间发布 | P1 |
| VID-05 | 多P投稿 | 一个稿件包含多个视频（合集式） | P2（V2） |
| VID-06 | 稿件编辑 | 已发布稿件可改标题/简介/封面/标签（重新走审核），视频文件不可替换 | P1 |
| VID-07 | 稿件删除 | 软删除，播放数据保留用于统计 | P0 |

### 3.2 转码与存储（MVP）

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| VID-10 | 自动转码 | 上传完成即入队；输出 HLS（H.264 + AAC） | P0 |
| VID-11 | 清晰度档位 | MVP：360P/720P；V1：+1080P；V3：+4K（大会员） | P0 |
| VID-12 | 转码进度通知 | 站内通知 + 创作者中心状态展示 | P1 |
| VID-13 | 视频指纹 | 抽帧 hash 用于重复/搬运检测 | P2 |

### 3.3 稿件状态机

```
草稿 → 上传中 → 转码中 → 待审核 → ┬→ 已发布（开放浏览）
                                  ├→ 已驳回（可修改后重新提交）
                                  └→ 已锁定（违规下架，可申诉）
已发布 → 已删除（UP 主删除 / 管理员删除）
```

### 3.4 播放（MVP）

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| PLY-01 | HLS 播放器 | Web：hls.js；H5/小程序：原生 video + HLS 地址 | P0 |
| PLY-02 | 清晰度切换 | 手动切换 + 自动（按带宽）；未登录限 480P 以下，大会员解锁 4K | P0 |
| PLY-03 | 倍速播放 | 0.5x / 0.75x / 1x / 1.25x / 1.5x / 2x / 3x | P0 |
| PLY-04 | 进度记忆 | 服务端记录观看进度，跨端续播 | P0 |
| PLY-05 | 播放统计 | 播放量（>5s 有效播放去重计数）、完播率埋点 | P0 |
| PLY-06 | 快捷键 | 空格暂停、←→ 快进退 5s、↑↓ 音量、F 全屏、D 开关弹幕 | P1（Web） |
| PLY-07 | 画中画 / 网页全屏 | Web 小窗与网页全屏模式 | P1 |
| PLY-08 | 防盗链 | 播放地址签名 URL（有效期 2h）+ Referer 校验 | P0 |
| PLY-09 | 试看与限制 | 违规锁定视频不可播；地区限制（预留） | P2 |

### 3.5 视频详情页

- 标题、UP 主卡片（头像/昵称/粉丝数/关注按钮）、播放数/弹幕数/发布时间
- 互动栏：点赞/投币/收藏/转发（见互动 PRD）
- 简介折叠展开、标签跳转搜索
- 相关推荐列表（MVP 用同分区最热，V2 换算法推荐）
- 评论区（见互动 PRD）

## 4. 关键指标

- 上传成功率 ≥ 99%；1GB 文件转码完成 ≤ 15 分钟
- 播放起播时间 P90 < 1.5s；卡顿率 < 1%

## 5. 边界与异常

- 上传中断后 24h 内可续传，超时清理分片。
- 转码失败自动重试 2 次，仍失败则通知 UP 主并允许重传。
- 播放地址过期时播放器自动静默换取新地址续播。
