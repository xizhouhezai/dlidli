# PRD：会员与商业化

> 优先级：`P2` ｜ 版本：V3 ｜ 状态：草案

## 1. 商业化原则

- **体验优先**：不做贴片广告；广告仅限信息流原生卡片且有明确"广告"标识。
- **多元收入**：会员订阅（稳定）+ 打赏分成（社区）+ 广告（规模后）。

## 2. 大会员（V3）

### 2.1 权益设计

| 权益 | 免费用户 | 大会员 |
| --- | --- | --- |
| 清晰度 | 最高 1080P | 4K / HDR |
| 专属内容 | ❌ | 会员抢先看/专属稿件 |
| 身份标识 | ❌ | 粉色昵称 + 会员徽章 |
| 硬币 | 常规获取 | 每月赠 5 枚 + 经验加成 |
| 装扮 | 基础 | 专属头像框/空间皮肤 |

### 2.2 购买与续费

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| VIP-01 | 套餐 | 月度/季度/年度；连续包月（首月优惠） |
| VIP-02 | 支付 | 支付宝、微信支付；App 内购（V3 App） |
| VIP-03 | 订单系统 | 订单状态机、支付回调幂等、退款流程 |
| VIP-04 | 到期管理 | 到期前 3 天提醒；连续包月自动扣款与随时取消 |

## 3. 充电计划（观众打赏 UP 主）

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| CHG-01 | 充电入口 | 视频页/空间页"充电"按钮，档位 5/10/50/自定义（元） |
| CHG-02 | 分成 | UP 主 70% / 平台 30%；月度结算入创作者收益 |
| CHG-03 | 鸣谢 | 充电用户进入视频鸣谢名单（可匿名） |

## 4. 广告系统（V3 后期）

- 信息流原生广告位（首页每 10 卡 1 个，频控可配），明确广告标识与"不感兴趣"负反馈。
- 品牌起飞：UP 主/机构购买流量加热自己的稿件。
- 商单撮合（远期）：品牌方与 UP 主内容合作平台，平台抽佣。

## 5. 支付基础设施（前置依赖）

- 统一支付网关（支付宝/微信/内购适配器模式）
- 账户体系：现金账户（充电/激励结算）与虚拟币账户（硬币）严格分离
- 财务对账：日对账单、异常订单人工处理台
- 合规：增值电信业务许可、支付通道资质、未成年人消费限制

## 6. 指标

- 会员付费率 ≥ 3%（MAU 口径）；连续包月留存率 ≥ 80%
- 支付成功率 ≥ 99%；支付回调处理延迟 < 5s
