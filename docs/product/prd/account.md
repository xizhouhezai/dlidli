# PRD：用户账号体系

> 优先级：`P0` ｜ 版本：MVP 起 ｜ 状态：草案

## 1. 需求背景

账号是所有业务的基础。需支持多端统一账号（Web/H5/小程序/App 同一 UID），并承载社区成长体系（等级、硬币）。

## 2. 功能需求

### 2.1 注册与登录（MVP）

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| ACC-01 | 手机号注册/登录 | 短信验证码，一键注册即登录 | P0 |
| ACC-02 | 邮箱注册/登录 | 邮箱 + 密码，需邮件激活 | P0 |
| ACC-03 | 密码登录 | 手机号/邮箱 + 密码，连续错误 5 次锁定 15 分钟并要求图形验证码 | P0 |
| ACC-04 | 微信登录 | 小程序端必须；Web 扫码登录 | P1（V2 小程序同步） |
| ACC-05 | 找回密码 | 短信/邮件验证重置 | P0 |
| ACC-06 | 多端会话 | JWT（Access 2h + Refresh 30d），支持查看/踢出在线设备 | P0（踢出 P1） |
| ACC-07 | 注销账号 | 7 天冷静期，注销后数据匿名化 | P1 |

### 2.2 用户资料

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| ACC-10 | 基础资料 | 昵称（唯一，2-24 字符）、头像、签名、性别、生日 | P0 |
| ACC-11 | 头像上传 | 裁剪、审核（机审）后生效 | P0 |
| ACC-12 | 个人空间页 | 投稿列表、动态、收藏（可设隐私）、关注/粉丝数 | P0 基础 / P1 完整 |
| ACC-13 | 隐私设置 | 收藏夹/关注列表可见性开关 | P1 |

### 2.3 成长体系（V1）

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| ACC-20 | 经验等级 | Lv0-Lv6；经验来源：登录+5/日、观看+5/日、投稿+10、弹幕评论互动等；升级解锁权益（如 Lv1 可发弹幕、Lv3 可发彩色弹幕） | P1 |
| ACC-21 | 硬币系统 | 登录、投稿被赞等获取；用于投币；每日获取上限 | P1 |
| ACC-22 | 每日任务 | 任务列表 + 领取奖励 | P2 |
| ACC-23 | 实名认证 | 手机号实名（合规要求）；UP 主开通收益需身份证实名 | P1（收益前置） |

### 2.4 账号安全与风控

- 敏感操作（改密码/换绑手机）需二次验证。
- 设备指纹 + IP 风控：异地登录提醒；批量注册识别。
- 昵称/签名/头像走内容安全机审。

## 3. 关键流程

### 手机号验证码登录

```
输入手机号 → 图形验证码（风控触发时）→ 发送短信（60s 冷却，10 分钟有效）
→ 校验验证码 → 已注册？登录 ：自动注册（默认昵称 dli_xxxx）→ 颁发 JWT
```

## 4. 数据指标

- 注册转化率（进入注册页 → 完成注册）≥ 60%
- 短信到达率 ≥ 98%；登录接口 P99 < 300ms

## 5. 边界与异常

- 同一手机号 1 分钟内最多 1 条短信、1 天最多 10 条。
- 昵称冲突时自动追加随机后缀提示用户修改。
- 封禁用户登录时提示封禁原因与期限，提供申诉入口（V1）。
