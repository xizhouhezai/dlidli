# PRD：搜索与推荐

> 优先级：搜索 `P1`（V1）｜ 推荐 `P1`（V2） ｜ 状态：草案

## 1. 需求背景

搜索满足"确定性找内容"，推荐解决"逛"的效率。MVP 阶段用"分区 + 最新/最热"过渡，V1 上搜索，V2 上个性化推荐。

## 2. 搜索（V1）

### 2.1 功能需求

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| SRH-01 | 综合搜索 | 关键词搜视频（标题/简介/标签），Tab 切换：视频 / UP 主 /（V2+：动态、直播） | P1 |
| SRH-02 | 排序与筛选 | 排序：综合/最多播放/最新发布/最多弹幕；筛选：分区、时长、发布时间 | P1 |
| SRH-03 | 搜索联想 | 输入即联想（Prefix + 拼音），高亮匹配 | P1 |
| SRH-04 | 搜索历史 | 本地 + 云端同步，可单删/清空 | P1 |
| SRH-05 | 热搜榜 | 实时热搜 Top10（运营可置顶/屏蔽） | P1 |
| SRH-06 | 搜索无结果 | 推荐相近内容 + 纠错提示（"你是不是要找 xx"） | P2 |

### 2.2 技术要点

- Elasticsearch（IK 中文分词），稿件发布/编辑/删除通过消息队列同步索引（延迟 < 10s）。
- 综合排序因子：文本相关性 × 质量分（播放/互动）× 时效衰减。
- 敏感词搜索拦截；搜索结果过滤未过审/已删除稿件。

## 3. 推荐（V2）

### 3.1 场景

| 场景 | 说明 | 优先级 |
| --- | --- | --- |
| 首页信息流 | 个性化"猜你喜欢"，瀑布流/网格卡片，下拉刷新换一批 | P1 |
| 相关推荐 | 播放页右侧/下方"接下来播放" | P1 |
| 热门/排行榜 | 全站热门、分区排行榜（周维度）、每周必看 | P1 |
| 冷启动 | 新用户选兴趣分区（≥3 个）；新稿件小流量试探 | P1 |

### 3.2 推荐策略演进

```
V2.0 起步：热度榜 + 协同过滤（ItemCF）+ 关注 UP 主加权 → 规则粗排
V2.5 进阶：向量召回（双塔）+ 轻量精排模型（GBDT/LR）
V3.0+：深度模型 + 多目标（点击/时长/互动）排序
```

### 3.3 推荐体验规则

- 多样性：同一 UP 主在一屏内最多出现 1 次；同分区连续不超过 3 个。
- 负反馈："不感兴趣"（内容/UP 主/分区维度），7 天内不再推荐同类。
- 已看过滤：近 30 天完整观看过的视频不重复推荐。
- 新稿扶持：新发布稿件保底曝光池，按 CTR/完播率决定是否放量。

## 4. 指标

- 搜索：无结果率 < 8%；搜索→播放转化 ≥ 40%；搜索响应 P99 < 500ms。
- 推荐：首页 CTR ≥ 8%；人均观看时长周环比提升；推荐接口 P99 < 300ms。
