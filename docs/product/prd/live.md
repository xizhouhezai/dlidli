# PRD：直播（远期 V3）

> 优先级：`P2` ｜ 版本：V3 ｜ 状态：预研草案

## 1. 需求背景

直播提升用户时长与商业化空间（礼物打赏），并为 UP 主提供第二收入曲线。属 V3 远期规划，本文档为范围预研，开发前需细化。

## 2. 功能范围（第一期）

### 2.1 主播侧

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| LIV-01 | 开播资格 | 实名认证 + 粉丝 ≥ 100（初期白名单制） |
| LIV-02 | 开播管理 | 房间标题/封面/分区、RTMP 推流地址+密钥（配合 OBS）、开播/下播 |
| LIV-03 | 直播预告 | 关联动态发布预告，开播提醒粉丝 |
| LIV-04 | 房管 | 任命房管、禁言用户、弹幕关键词屏蔽 |

### 2.2 观众侧

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| LIV-10 | 直播间列表 | 直播首页（推荐 + 分区）、关注的主播开播提醒 |
| LIV-11 | 观看 | HLS/HTTP-FLV 拉流，清晰度切换，人气值展示 |
| LIV-12 | 直播弹幕 | 实时聊天弹幕（WebSocket），进场消息，弹幕频控 |
| LIV-13 | 礼物打赏 | 充值金瓜子 → 赠送礼物 → 礼物特效 → 主播分成 |
| LIV-14 | 直播回放 | 下播后自动生成回放稿件（主播可选发布） |

## 3. 技术预研要点

- 推流：RTMP 接入 → 转码集群（多码率）→ CDN 分发（HLS 延迟 6-15s；后续 HTTP-FLV/WebRTC 降至 3s 内）。
- 直播弹幕网关：单房间 10 万连接目标，分层广播（网关分片 + 房间维度聚合）。
- 礼物链路强一致：充值/扣款/分成走支付系统事务 + 对账。
- 内容安全：直播截帧机审（每 10s）+ 人工巡查 + 快速切断机制。

## 4. 合规前置

- 网络文化经营许可证 / 直播相关资质
- 主播实名 + 未成年人打赏限制与退款通道
- 直播内容存档 ≥ 60 天（监管要求）
