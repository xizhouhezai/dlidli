# PRD：创作者中心

> 优先级：`P1` ｜ 版本：MVP（基础投稿管理）→ V2（完整） ｜ 状态：草案 ｜ 更新：2026-08-04
>
> 2026-08-04 更新：CRT-10 数据趋势扩展——统计卡 5 项指标（总播放/点赞/投币/粉丝/收益）均可查看趋势，指标粒度细化（点赞/投币/收藏/涨粉/收益/互动/点击/曝光），趋势图升级 echarts。

## 1. 需求背景

创作者是内容供给侧的根本。创作者中心提供"投稿管理 → 数据洞察 → 粉丝运营 → 收益变现"一站式工作台（Web 为主，H5 提供数据概览）。

## 2. 功能需求

### 2.1 稿件管理（MVP 基础）

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| CRT-01 | 稿件列表 | 按状态筛选（进行中/已发布/已驳回/已锁定），展示核心数据（播放/点赞/评论） | P0 |
| CRT-02 | 状态跟踪 | 上传→转码→审核进度可视化；驳回原因展示 | P0 |
| CRT-03 | 稿件编辑/删除 | 入口复用投稿流程 | P0 |
| CRT-04 | 评论管理 | 集中查看/回复/删除/置顶自己稿件的评论 | P1 |
| CRT-05 | 弹幕管理 | 查看/删除自己稿件的弹幕、关键词黑名单 | P2 |

### 2.2 数据中心（V2）

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| CRT-10 | 概览看板 | 昨日/近7日/近30日：播放、观看时长、互动、涨粉，环比趋势图 | P1 | ✅ 2026-08-04（近 7/30 日 + **9 项指标切换**：有效播放/点赞/投币/收藏/涨粉/收益/互动/点击/曝光；数据源：行为日志（播放/互动/点击/曝光）、user_action（点赞/投币/收藏）、relation（涨粉）、日结算（收益）；echarts 柱状图；观看时长待行为数据扩展） |
| CRT-11 | 单稿分析 | 播放来源（推荐/搜索/关注/其他）、观众留存曲线、互动漏斗 | P1 |
| CRT-12 | 粉丝画像 | 性别/年龄/地域/活跃时段分布（脱敏聚合） | P2 |
| CRT-13 | 数据对比 | 多稿件横向对比 | P2 |

### 2.3 粉丝运营（V2）

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| CRT-20 | 粉丝列表 | 新增粉丝、铁粉标识（高互动粉丝） | P2 |
| CRT-21 | 动态发布入口 | 快捷发布图文动态、预告 | P1 |

### 2.4 收益中心（V2 末 / V3）

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| CRT-30 | 创作激励 | 按有效播放计算激励金（需实名 + 粉丝≥1000 或播放≥10万开通） | P1（V2） |
| CRT-31 | 充电收入 | 观众打赏分成（平台抽成 30%） | P1（V3） |
| CRT-32 | 提现 | 绑定支付宝/银行卡，月度结算，个税代扣提示 | P1（V3） |
| CRT-33 | 收益明细 | 按日/按稿件的收益流水 | P1（V3） |

### 2.5 创作辅助（远期）

- 热门选题灵感（分区热点话题）
- 封面模板工具、AI 字幕生成
- 违规预检（发布前自查提示）

## 3. 指标

- 投稿次日留存（发布第 2 稿比例）≥ 30%
- 数据看板 T+1 更新准时率 100%（核心指标 V2.5 起准实时）
