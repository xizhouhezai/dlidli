# 非功能需求（性能 / 安全 / 合规）

> 优先级：`P0` ｜ 状态：草案

## 1. 性能与容量

### 1.1 性能指标（SLO）

| 指标 | 目标 |
| --- | --- |
| API 响应 | 读接口 P99 < 300ms，写接口 P99 < 500ms |
| 视频起播时间 | P90 < 1.5s |
| 播放卡顿率 | < 1% |
| 首页首屏（Web/H5） | LCP < 2.5s |
| 服务可用性 | 核心链路（登录/播放）99.9%，其他 99.5% |

### 1.2 容量规划（一年内目标）

| 维度 | 规划值 |
| --- | --- |
| 注册用户 | 100 万 |
| DAU | 10 万 |
| 峰值 QPS | API 5000，播放并发 1 万 |
| 日新增稿件 | 5000 个（平均 500MB/个） |
| 存储增量 | ≈ 5TB/日（源片 + 多清晰度） |

## 2. 安全需求

| 类别 | 要求 |
| --- | --- |
| 传输 | 全站 HTTPS；WebSocket 走 WSS |
| 认证 | JWT 短期 Access + Refresh 轮换；敏感操作二次验证 |
| 密码 | bcrypt 加盐存储；弱密码拦截 |
| 接口 | 参数校验（防注入/XSS）、CSRF 防护、接口签名（小程序/App） |
| 限流 | 网关级 IP/UID 维度限流；核心写接口幂等键 |
| 数据 | 手机号/身份证加密存储（AES-GCM），日志脱敏 |
| 防盗链 | 播放/图片 URL 签名 + Referer 校验 |
| 风控 | 设备指纹、验证码（注册/登录/高频操作）、刷量识别 |
| 审计 | 后台操作全量审计日志，保留 ≥ 1 年 |

## 3. 合规需求（中国大陆运营前提）

| 项 | 说明 |
| --- | --- |
| ICP 备案/许可证 | 网站备案 + 经营性 ICP；视听节目相关资质评估 |
| 内容安全 | 先审后播；敏感词库；不良信息举报入口（页面底部） |
| 实名制 | 发布内容（弹幕/评论/投稿）需手机号实名 |
| 个人信息保护 | 《个保法》合规：隐私政策、单独同意、注销权、数据导出 |
| 未成年人保护 | 青少年模式（时长限制、内容池、消费限制）——V1 必须 |
| 算法合规 | 推荐算法备案（V2 前）；提供"关闭个性化推荐"开关 |
| 日志留存 | 网络日志留存 ≥ 6 个月 |

## 4. 可用性与运维

- 灰度发布：网关按 UID 尾号/白名单分流；前端灰度开关。
- 降级预案：推荐降级为热榜、弹幕降级为只读、评论降级为延迟展示。
- 备份：数据库每日全量 + binlog 增量；对象存储跨区域冗余。
- 监控告警：Prometheus + Grafana；核心链路（登录/上传/转码/播放）拨测。
