# 产品概述

> 文档状态：`V1.0 草案` ｜ 负责人：产品组 ｜ 更新日期：2026-07-28

## 1. 产品定位

**DliDli** 是一个以 **PUGC（专业用户生产内容）视频** 为核心、以 **弹幕互动文化** 为特色的年轻人视频社区，对标哔哩哔哩（bilibili）。

一句话定位：**让每个创作者都能被看见，让每次观看都有陪伴感（弹幕）。**

### 1.1 核心价值主张

| 角色 | 价值 |
| --- | --- |
| 观众 | 高质量分区内容 + 弹幕陪伴式观看 + 无贴片广告的干净体验 |
| 创作者（UP主） | 低门槛投稿、流量扶持、数据分析、创作收益 |
| 平台 | 通过社区文化建立高粘性，通过会员/直播/广告实现商业化 |

### 1.2 与竞品差异

| 维度 | DliDli | 抖音/快手 | 爱优腾 |
| --- | --- | --- | --- |
| 内容形态 | 中长视频为主（1-30min） | 短视频 | 长视频版权内容 |
| 内容来源 | PUGC 创作者 | UGC | OGV 采购 |
| 互动核心 | 弹幕 + 三连（点赞/投币/收藏） | 点赞/评论 | 评论 |
| 社区属性 | 强（分区圈层文化） | 中 | 弱 |

## 2. 目标与北极星指标

| 阶段 | 北极星指标 | 辅助指标 |
| --- | --- | --- |
| MVP（0-3月） | 周活跃观看用户 | 投稿量、播放完成率 |
| V1（3-6月） | DAU / 人均观看时长 | 弹幕发送率、三连率 |
| V2（6-12月） | 月活跃创作者数 | 关注转化率、留存率（次日/7日） |
| V3（12月+） | 商业化收入 | 会员付费率、直播渗透率 |

## 3. 产品范围

### 3.1 终端范围

| 终端 | 优先级 | 说明 |
| --- | --- | --- |
| Web（PC 浏览器） | P0 | 首发端，观看 + 投稿 + 创作者中心全功能 |
| H5（移动端网页） | P0 | 观看与互动为主，投稿引导到 Web |
| 微信小程序 | P1 | 轻量观看端，社交裂变入口 |
| 移动端 App（iOS/Android） | P2（远期） | 全功能 + 离线缓存 + 推送 |
| 管理后台（内部） | P0 | 内容审核、用户管理、运营配置 |

### 3.2 功能模块地图

```
DliDli
├── C 端
│   ├── 用户账号体系      （注册登录、资料、等级、实名）
│   ├── 视频投稿与播放    （上传、转码、多清晰度播放、分区）
│   ├── 弹幕系统          （发送、展示、屏蔽、高级弹幕）
│   ├── 互动体系          （点赞、投币、收藏、评论、转发、三连）
│   ├── 搜索与推荐        （搜索、热榜、首页推荐、相关推荐）
│   ├── 社区动态与关注    （关注流、动态发布、话题）
│   ├── 消息通知          （回复/点赞/系统通知、私信）
│   ├── 创作者中心        （稿件管理、数据分析、粉丝管理、收益）
│   ├── 直播（远期）      （开播、观看、直播弹幕、礼物）
│   └── 会员与商业化      （大会员、充电打赏、广告位）
└── B 端（内部）
    └── 内容审核与管理后台（稿件审核、用户处罚、分区运营、数据大盘）
```

各模块详细需求见左侧「功能需求（PRD）」章节。

## 4. 关键业务流程（概览）

### 4.1 投稿到消费主流程

```
UP主上传视频 → 云端转码（多清晰度） → 机审 + 人工审核 → 发布进入分区
→ 推荐/搜索分发 → 观众观看 → 弹幕/三连互动 → 数据回流创作者中心
```

### 4.2 用户增长循环

```
优质内容 → 吸引观众 → 互动数据反馈 → 激励创作者 → 更多优质内容
```

## 5. 名词表

| 名词 | 说明 |
| --- | --- |
| UP主 | 视频创作者/投稿者 |
| 稿件 | 一次投稿的视频（可含多分P） |
| 分P | 一个稿件下的多个视频段（合集式投稿） |
| 三连 | 点赞 + 投币 + 收藏的组合操作 |
| 投币 | 用户用平台虚拟币（硬币）支持视频，影响权重 |
| 弹幕 | 叠加在视频画面上按时间轴滚动的用户评论 |
| 分区 | 内容频道分类（如：科技、游戏、生活、动画等） |
| 大会员 | 付费会员，享清晰度/专属内容等权益 |
| 充电 | 观众对 UP 主的直接打赏 |
