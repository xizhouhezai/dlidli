# 用户画像与场景

> 文档状态：`V1.0 草案` ｜ 更新日期：2026-07-28

## 1. 目标用户画像

### P1：内容消费者「小观」

| 属性 | 描述 |
| --- | --- |
| 年龄 / 身份 | 16-30 岁，学生、年轻白领 |
| 使用动机 | 娱乐消遣、学习知识（教程/科普）、追更喜欢的 UP 主 |
| 使用场景 | 通勤路上刷 H5/小程序，晚上在 PC 上长时间观看 |
| 核心诉求 | 内容质量高、播放流畅、弹幕氛围好、不被广告打扰 |
| 痛点 | 找不到感兴趣内容、清晰度低、弹幕遮挡剧情 |

### P2：视频创作者「小 UP」

| 属性 | 描述 |
| --- | --- |
| 年龄 / 身份 | 18-35 岁，学生、自由职业者、垂类爱好者 |
| 使用动机 | 分享表达、积累粉丝、获得收益 |
| 使用场景 | 在 PC 上剪辑后通过 Web 端投稿，日常用手机查看数据和回复评论 |
| 核心诉求 | 上传快、审核快、有流量、数据透明、收益可观 |
| 痛点 | 冷启动没流量、审核慢/规则不透明、数据分析能力弱 |

### P3：平台运营/审核「小管」（内部用户）

| 属性 | 描述 |
| --- | --- |
| 身份 | 内容审核员、社区运营、数据运营 |
| 核心诉求 | 审核效率高（机审预筛 + 人审复核）、处罚可追溯、运营位可配置 |
| 痛点 | 审核积压、误判申诉处理繁琐 |

## 2. 核心使用场景（User Story）

### 观看侧

1. 作为**游客**，我可以浏览首页推荐和观看视频（限 480P），以便无门槛体验产品。
2. 作为**观众**，我可以在观看时发送弹幕，以便和"同屏的人"实时互动。
3. 作为**观众**，我可以对喜欢的视频一键三连，以便表达支持并帮助 UP 主获得流量。
4. 作为**观众**，我可以关注 UP 主并在动态页看到其更新，以便不错过追更内容。
5. 作为**通勤用户**，我可以在 H5/小程序上继续观看 PC 端的历史进度，以便跨端无缝衔接。

### 创作侧

6. 作为**UP主**，我可以上传视频、填写标题/封面/分区/标签并提交审核，以便发布作品。
7. 作为**UP主**，我可以在创作者中心查看播放/互动/粉丝数据趋势，以便优化创作方向。
8. 作为**UP主**，我可以回复和置顶评论，以便运营粉丝关系。

### 管理侧

9. 作为**审核员**，我可以在审核队列中查看机审标记的风险点并做出通过/驳回决定。
10. 作为**运营**，我可以配置首页 Banner、分区置顶和热搜词，以便进行内容运营。
