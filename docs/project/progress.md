## 5. 进度管理规则

1. **看板流转**：任务状态 `待办 → 开发中 → 联调 → 测试 → 完成`；单人在制品（WIP）≤ 2。
2. **周会节奏**：周一计划会（领任务）、周五站会（更新本页 + 风险上报）。
3. **延期处理**：预计延期 > 3 天须在"阻塞与风险"表报备，并给出砍范围/加资源/顺延三选一决策。
4. **验收口径**：功能完成 = 代码合并 + 自测通过 + 联调通过 + 文档更新（接口重跑 swag / tasks 勾选 + 覆盖需求核对）。
5. **变更控制**：需求变更须先更新对应模块 `specs/*/spec.md`（含 changelog 与日期），并在 [Roadmap 变更记录](/project/roadmap#_4-变更记录) 登记；SDD 流程详见 [协作规范](/project/conventions) 与 [SDD 总纲](/specs/)。
