## 1. 背景与用户故事

弹幕是产品差异化核心，营造"一起看"的陪伴感。需兼顾表达自由与观看体验（防遮挡、防刷屏）；进阶目标是在基础弹幕之上补齐**样式选择、列表面板、屏蔽治理、实时下发**四大能力。

- 作为 **Lv1+ 观众**，我可以发送弹幕并选择模式与颜色，以便个性化表达。
- 作为 **观众**，我可以屏蔽关键词/用户与调节展示密度，以便守护自己的观看体验。
- 作为 **同视频观众**，我发送的弹幕可实时出现在其他在线观众的屏幕上，以便形成"同屏共时"氛围。

## 2. 需求规格

### 2.1 弹幕发送

| ID | 需求 | 验收标准（EARS） | 优先级 |
| --- | --- | --- | --- |
| DM-01 | 发送滚动弹幕 | **WHEN** Lv1 及以上登录用户发送 ≤ 100 字弹幕 **THE SYSTEM SHALL** 接受并绑定视频时间点（毫秒） | P0 |
| DM-02 | 弹幕样式 | **THE SYSTEM SHALL** 提供字号（小/标准）与颜色选择（白色默认；彩色需 Lv3，服务端校验） | P1 |
| DM-03 | 弹幕模式 | **THE SYSTEM SHALL** 提供滚动（默认）/ 顶部固定 / 底部固定三种模式（顶/底需 Lv3） | P1 |
| DM-04 | 发送频控 | **IF** 同一用户在同一视频 5s 内已发送弹幕 **THEN THE SYSTEM SHALL** 拒绝；**IF** 同视频 30s 内发送重复内容 **THEN THE SYSTEM SHALL** 去重拒绝 | P0 |
| DM-05 | 高级弹幕 | **WHERE** 用户消耗硬币发送高级弹幕 **THE SYSTEM SHALL** 支持自定义位置/动画 | P3（远期） |

### 2.2 弹幕展示

| ID | 需求 | 验收标准（EARS） | 优先级 |
| --- | --- | --- | --- |
| DM-10 | 时间轴加载 | **THE SYSTEM SHALL** 按分段（6min/段）拉取弹幕，随播放进度渲染并预取下一段 | P0 |
| DM-11 | 弹幕开关 | **THE SYSTEM SHALL** 提供一键开/关并记忆状态 | P0 |
| DM-12 | 展示设置 | **THE SYSTEM SHALL** 提供设置面板：不透明度（默认 80%）、字号缩放（默认 100%）、显示区域（1/4 屏/半屏/全屏）、滚动速度（慢/标准/快） | P1 |
| DM-13 | 密度控制 | **THE SYSTEM SHALL** 提供同屏密度上限（默认自适应），超出按权重丢弃（优先保留高等级用户弹幕） | P1 |
| DM-15 | 实时弹幕 | **WHEN** 同视频在线观众发送弹幕成功 **THE SYSTEM SHALL** 经 WebSocket 即时推送上屏；断线自动重连；WS 不可用时回退 HTTP 分段拉取 | P1 |
| DM-16 | 弹幕列表面板 | **THE SYSTEM SHALL** 提供独立弹窗：按时间排序的全量列表（分页），点击条目跳转播放进度，条目支持复制/举报/屏蔽发送者 | P1 |
| DM-17 | 悬停操作 | **WHEN** 悬停弹幕 **THE SYSTEM SHALL** 暂停滚动并提供操作：复制/举报/屏蔽发送者（点赞延后，复用 user_action obj_type=3） | P1 |
| DM-14 | 防挡字幕 | **WHEN** 渲染弹幕 **THE SYSTEM SHALL** 智能避让人脸/字幕区域 | P3（远期） |

### 2.3 弹幕治理

| ID | 需求 | 验收标准（EARS） | 优先级 |
| --- | --- | --- | --- |
| DM-20 | 关键词屏蔽 | **WHERE** 用户配置屏蔽词（≤ 200 个）**THE SYSTEM SHALL** 服务端账号级存储（跨设备生效），命中词不渲染（含实时弹幕） | P1 |
| DM-21 | 屏蔽用户 | **WHERE** 用户屏蔽某发送者 **THE SYSTEM SHALL** 按其 UID 哈希存储（不暴露 UID），命中不渲染 | P1 |
| DM-22 | 弹幕举报 | **WHEN** 用户举报弹幕 **THE SYSTEM SHALL** 按 6 类举报类型（违法违规/色情低俗/人身攻击/垃圾广告/剧透/其他）受理并入举报处理体系（见 [admin spec](/specs/admin/spec) ADT-10） | P1 |
| DM-23 | UP 主弹幕管理 | **WHERE** UP 主管理自己视频 **THE SYSTEM SHALL** 支持删除弹幕与设置弹幕关键词黑名单 | P2（延后） |
| DM-24 | 机审过滤 | **WHEN** 弹幕提交 **THE SYSTEM SHALL** 先经敏感词 + 内容安全（contentmod）过滤，命中影子屏蔽（发送者可见、他人不可见） | P0 |

## 3. 边界与异常

- **IF** 视频处于锁定状态 **THEN THE SYSTEM SHALL** 停止对外展示其弹幕。
- **IF** 单视频单段（6min）弹幕超过池上限（8000 条）**THEN THE SYSTEM SHALL** 按权重淘汰展示。
- **IF** 单视频 WS 在线连接超过上限（5000）**THEN THE SYSTEM SHALL** 超出部分回退 HTTP 拉取。
