## 1. 背景与商业化原则

- **体验优先**：不做贴片广告；广告仅限信息流原生卡片且有明确"广告"标识。
- **多元收入**：会员订阅（稳定）+ 打赏分成（社区）+ 广告（规模后）。

用户故事：

- 作为 **观众**，我可以购买大会员获得清晰度/专属内容权益，以便更好的观看体验。
- 作为 **观众**，我可以给喜欢的 UP 主充电，以便直接支持创作。
- 作为 **UP 主**，我可以获得充电分成与创作激励，以便持续创作。

## 2. 需求规格

### 2.1 大会员权益（V3）

| 权益 | 免费用户 | 大会员 |
| --- | --- | --- |
| 清晰度 | 最高 1080P | 4K / HDR |
| 专属内容 | 无 | 会员抢先看/专属稿件 |
| 身份标识 | 无 | 粉色昵称 + 会员徽章 |
| 硬币 | 常规获取 | 每月赠 5 枚 + 经验加成 |
| 装扮 | 基础 | 专属头像框/空间皮肤 |

### 2.2 购买与续费（V3）

| ID | 需求 | 验收标准（EARS） | 优先级 |
| --- | --- | --- | --- |
| VIP-01 | 套餐 | **THE SYSTEM SHALL** 提供月度/季度/年度套餐与连续包月（首月优惠） | P2 |
| VIP-02 | 支付 | **THE SYSTEM SHALL** 支持支付宝、微信支付；App 内购（V3 App） | P2 |
| VIP-03 | 订单系统 | **THE SYSTEM SHALL** 维护订单状态机，支付回调幂等，支持退款流程 | P2 |
| VIP-04 | 到期管理 | **WHEN** 会员到期前 3 天 **THE SYSTEM SHALL** 提醒；连续包月自动扣款且可随时取消 | P2 |

### 2.3 充电计划（观众打赏 UP 主）

| ID | 需求 | 验收标准（EARS） | 优先级 |
| --- | --- | --- | --- |
| CHG-01 | 充电入口 | **THE SYSTEM SHALL** 在视频页/空间页提供"充电"按钮，档位 5/10/50/自定义（元） | P2 |
| CHG-02 | 分成 | **WHEN** 观众充电 **THE SYSTEM SHALL** 按 UP 主 70% / 平台 30% 分成，月度结算入创作者收益（对齐 [creator spec](/specs/creator/spec) CRT-31） | P2 |
| CHG-03 | 鸣谢 | **THE SYSTEM SHALL** 将充电用户列入视频鸣谢名单（可匿名） | P2 |

### 2.4 广告系统（V3 后期）

### 2.5 支付基础设施（前置依赖）

| ID | 需求 | 验收标准（EARS） | 优先级 |
| --- | --- | --- | --- |
| PAY-01 | 支付基础设施（迁移补录） | **THE SYSTEM SHALL** 提供统一支付网关（支付宝/微信/内购适配器模式）；现金账户与虚拟币账户（硬币）严格分离；日对账单与异常订单人工处理台；满足增值电信/支付通道/未成年人消费限制合规 | P2（前置） |

## 3. 边界与异常

- **IF** 支付回调重复到达 **THEN THE SYSTEM SHALL** 以幂等键保证只结算一次。
- **IF** 用户为未成年人 **THEN THE SYSTEM SHALL** 执行消费限制（合规）。

## 4. 成功指标

| 指标 | 目标 |
| --- | --- |
| 会员付费率（MAU 口径） | ≥ 3% |
| 连续包月留存率 | ≥ 80% |
| 支付成功率 | ≥ 99% |
| 支付回调处理延迟 | < 5s |
