## 1. 背景与用户故事

搜索满足"确定性找内容"，推荐解决"逛"的效率。MVP 阶段用"分区 + 最新/最热"过渡，V1 上搜索，V2 上个性化推荐。

- 作为 **观众**，我可以用关键词搜索视频与 UP 主，以便找到确定的内容。
- 作为 **观众**，首页能推荐我感兴趣的内容并对负反馈敏感，以便高效"逛"。
- 作为 **新 UP 主**，我的新稿件有保底曝光机会，以便冷启动被看见。

## 2. 需求规格

### 2.1 搜索（V1）

| ID | 需求 | 验收标准（EARS） | 优先级 |
| --- | --- | --- | --- |
| SRH-01 | 综合搜索 | **WHEN** 用户输入关键词 **THE SYSTEM SHALL** 搜索视频（标题/简介/标签），Tab 切换视频 / UP 主（V2+：动态、直播） | P1 |
| SRH-02 | 排序与筛选 | **THE SYSTEM SHALL** 支持排序（综合/最多播放/最新发布/最多弹幕）与筛选（分区、时长、发布时间） | P1 |
| SRH-03 | 搜索联想 | **WHEN** 用户输入 **THE SYSTEM SHALL** 即时联想（Prefix + 拼音）并高亮匹配 | P1 |
| SRH-04 | 搜索历史 | **THE SYSTEM SHALL** 本地 + 云端同步历史，可单删/清空 | P1 |
| SRH-05 | 热搜榜 | **THE SYSTEM SHALL** 提供实时热搜 Top10（运营可置顶/屏蔽） | P1 |
| SRH-06 | 搜索无结果 | **IF** 搜索无结果 **THEN THE SYSTEM SHALL** 推荐相近内容并给出纠错提示（"你是不是要找 xx"） | P2 |

### 2.2 推荐场景（V2）

| ID | 需求 | 验收标准（EARS） | 优先级 |
| --- | --- | --- | --- |
| REC-01 | 首页信息流（迁移补录） | **THE SYSTEM SHALL** 提供个性化"猜你喜欢"（网格卡片，下拉刷新换一批） | P1 |
| REC-02 | 相关推荐（迁移补录） | **THE SYSTEM SHALL** 在播放页提供"接下来播放"（承接 [video spec](/specs/video/spec) PLY-31） | P1 |
| REC-03 | 热门/排行榜（迁移补录） | **THE SYSTEM SHALL** 提供全站热门、分区排行榜（周维度）、每周必看 | P1 |
| REC-04 | 冷启动（迁移补录） | **WHEN** 新用户进入 **THE SYSTEM SHALL** 引导选择兴趣分区（≥ 3 个）；新稿件小流量试探 | P1 |

### 2.3 推荐体验规则（V2）

| ID | 需求 | 验收标准（EARS） | 优先级 |
| --- | --- | --- | --- |
| REC-10 | 多样性打散（迁移补录） | **THE SYSTEM SHALL** 保证同一 UP 主一屏最多出现 1 次、同分区连续不超过 3 个 | P1 |
| REC-11 | 负反馈（迁移补录） | **WHEN** 用户点击"不感兴趣"（内容/UP 主/分区维度）**THE SYSTEM SHALL** 7 天内不再推荐同类 | P1 |
| REC-12 | 已看过滤（迁移补录） | **THE SYSTEM SHALL** 过滤近 30 天完整观看过的视频 | P1 |
| REC-13 | 新稿扶持（迁移补录） | **THE SYSTEM SHALL** 为新发布稿件提供保底曝光池，按 CTR/完播率决定放量 | P1 |
| REC-14 | 个性化推荐开关（迁移补录） | **WHERE** 用户关闭个性化推荐 **THE SYSTEM SHALL** 退化为非个性化榜单（算法合规，见 [nfr](/product/nfr)） | P1（合规） |

## 3. 边界与异常

- **IF** 搜索词命中敏感词 **THEN THE SYSTEM SHALL** 拦截搜索。
- **THE SYSTEM SHALL NOT** 在搜索/推荐结果中返回未过审或已删除稿件。

## 4. 成功指标

| 指标 | 目标 |
| --- | --- |
| 搜索无结果率 | < 8% |
| 搜索→播放转化 | ≥ 40% |
| 搜索响应 | P99 < 500ms |
| 首页推荐 CTR | ≥ 8% |
| 推荐接口 | P99 < 300ms |

## 5. 依赖与关联

- 依赖：稿件元数据与状态（[video spec](/specs/video/spec)）；行为日志（曝光/点击/播放/互动，本模块基建）；用户兴趣分区
- 被依赖：A/B 实验框架（[admin spec](/specs/admin/spec) OPS-06）承接推荐策略变体；负反馈与已看过滤消费用户行为数据
