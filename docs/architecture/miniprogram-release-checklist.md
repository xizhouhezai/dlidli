# 微信小程序发布验收清单（M3-MP-03）

> 代码侧分享已接入；本清单用于真实 AppID、开发者账号和视频类目资质到位后的最后验收。

## 发布前配置

- [ ] 在微信公众平台创建/确认小程序主体和 AppID。
- [ ] 将真实 AppID 写入本地 `apps/h5/src/manifest.json` 的 `mp-weixin.appid`；AppID 不提交到不应暴露的环境配置中。
- [ ] 后端通过部署密钥注入 `DLIDLI_WECHAT_MPAPPID` 与 `DLIDLI_WECHAT_MPAPPSECRET`；Secret 禁止写入仓库、日志和前端产物。
- [ ] 在微信公众平台配置服务器域名，至少包含 API、静态资源和视频播放域名，并完成 HTTPS 证书校验。
- [ ] 确认后端部署环境能访问微信 `jscode2session` 接口。

## 构建与导入

```bash
pnpm mp:build
```

- [ ] 构建成功，导入 `apps/h5/dist/build/mp-weixin`。
- [ ] 主包大小保持在 1.5MB 目标以内（当前约 203KB）。
- [ ] 微信开发者工具无编译错误、无域名校验错误、无敏感信息泄露。

## 功能验收

- [ ] 首页加载、分类横向滚动、下拉刷新、触底分页正常。
- [ ] 搜索输入、搜索结果分页和空结果状态正常。
- [ ] 播放页加载视频、播放进度、弹幕和互动操作正常。
- [ ] 个人中心未登录状态显示微信一键登录入口。
- [ ] 调用微信一键登录后，后端返回 JWT；首次登录创建账号，再次登录复用同一账号。
- [ ] 未配置小程序凭据时返回“微信登录未启用”，不影响服务启动。

## 分享验收

- [ ] 播放页右上角/分享菜单出现好友分享入口。
- [ ] 好友卡片标题使用视频标题，封面使用视频封面，无封面时使用默认封面。
- [ ] 好友卡片路径为 `/pages/video/video?bvid=<值>`，打开后能定位原视频。
- [ ] 朋友圈分享标题和 `bvid` 查询参数正确。
- [ ] 分享到会话后冷启动、未登录访问和已登录访问均正常。

## 资质提审

- [ ] 申请并通过微信视频号/短视频相关类目资质（按平台当前要求准备主体、版权、内容安全和审核材料）。
- [ ] 完成隐私保护指引、用户协议、内容投诉/举报入口和注销/账号删除说明。
- [ ] 开发版、体验版完成功能回归后提交审核。
- [ ] 记录审核版本、提审时间、审核反馈和补件结果；通过后更新本清单与 `docs/project/roadmap.md`。

## 当前外部阻塞

本机已安装微信开发者工具 CLI，但没有真实小程序 AppID、Secret 和视频类目资质，因此当前只能完成构建产物与代码级分享验收；不能把真实分享菜单、微信卡片和平台提审标记为完成。
