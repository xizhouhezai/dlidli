# packages（前端共享包）

| 包 | 职责 | 初始化里程碑 |
| --- | --- | --- |
| `api-client` | OpenAPI 生成 TS 类型 + 多端请求适配（fetch / uni.request） | M0-ENG-11 |
| `shared` | 工具函数、常量、业务模型（纯 TS） | M0-ENG-12 |
| `ui` | PC 业务组件库（Element Plus 二次封装） | M1 |
| `player` | 播放器内核（hls.js + Canvas 弹幕引擎） | M1-VID-09 |

详见：[前端架构](../docs/architecture/frontend.md)
